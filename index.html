How it works

Environment

A randomly generated N×N grid with configurable obstacles. A BFS check ensures the goal is always reachable before the agent starts.

DQN Agent

A neural network (28→128→128→4) trained with experience replay and a target network. Input is a 5×5 local view, relative goal direction, and previous action.

Reward shaping

+15 reaching goal. −1 timeout. −0.15 per step. +0.08 moving closer. −0.01 moving away. −5 hitting obstacle. -1 for invalid/no movement. -0.05 revisit penalty.

Browser inference

Trained PyTorch weights are exported to JSON. The forward pass runs entirely in JavaScript — no server, no Python needed.
